# 🐱 小团子（Tuanzi）

> 一只住在 Android 平板里的 QQ 机器人猫 —— 本地大模型驱动、全离线运行、自带可视化控制面板。

不用服务器、不用月租：一台闲置 Android 平板 + Termux，就能养一只会聊天、会看图、会发表情包、会记事的猫。

## ✨ 它会干什么

| 能力 | 说明 |
|---|---|
| 💬 聊天 | QQ 私聊 / 群聊，主动冒泡、@回应、深夜免打扰 |
| 🧠 双大脑 | **本地**（llama.cpp + GGUF 小模型，免费离线）或 **云端**（任何 OpenAI 兼容 API），面板一键切换 |
| 👁 看图说话 | 收到图片真的"看"一眼再回复（多模态模型） |
| 🗣 语音条 | Edge-TTS 生成语音消息 |
| 😸 表情包 | 按情绪智能挑选、触发词匹配、支持自定义上传（含示例 32 张） |
| 💾 记忆系统 | 分人档案 + 长期事实 + 每日日记，重启不丢 |
| ⏰ 更多 | 定时转达、QQ 空间关注、天气感知、节日/早晚安自动冒泡 |
| 🖥 控制面板 | 五页签 Web 面板（首页/玩它/聊天/档案/设置），手机浏览器即遥控器 |
| 🛡 宿主管家 | 24h 守护脚本：进程保活、日志轮转、内存看门狗、磁贴面板保活 |
| 📱 无 root 可跑 | root 环境体验更佳；无 root 也能通过 Termux + proot 完整运行 |

## 🏗️ 架构一览

```
┌─────────── Android 平板 ────────────┐
│  Termux (proot Ubuntu 沙箱)          │
│                                     │
│  ┌─────────┐   WS     ┌─────────┐   │
│  │ NapCat  │◄────────►│ 引擎    │   │
│  │ (QQ)    │          │tuanzi_  │   │
│  └─────────┘          │service  │   │
│       ▲               └──┬───┬──┘   │
│       │ HTTP             │   │      │
│  ┌────┴─────┐       ┌────┴┐ ┌┴────┐ │
│  │ QQ 服务器│       │面板  │ │llama│ │
│  └──────────┘       │server│ │.cpp │ │
│                     └───┬──┘ └─────┘ │
│  ┌──────────────────────┴──────┐    │
│  │ 宿主守护 (tuanzi_host_agent)│    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

- **引擎**：Python 单进程，收 QQ 消息 → 组上下文 → 调大脑 → 拆条回复（文字/语音/表情包）
- **面板**：Python 标准库 HTTP 服务 + 单文件 HTML（内嵌 CSS/JS，零依赖），5 秒轮询状态
- **宿主管家**：shell 循环脚本，负责保活/重启/日志/看门狗，让整只猫"打不死"
- **大脑抽象**：同一套消息协议下无缝切换 llama.cpp 本地推理或云端 API

## 🚀 快速开始（概览）

> 完整部署针对 Android 平板 + Termux 环境设计。

1. 平板安装 [Termux](https://f-droid.org/packages/com.termux/)（GitHub/F-Droid 版），架设 proot Ubuntu 沙箱
2. 安装 [NapCat](https://github.com/NapNeko/NapCatQQ)（QQ 的 OneBot 实现）并登录小号
3. 把 `engine/` + `panel/` + `scripts/` 部署进沙箱，填好 `config.example.json`（复制为 `config.json`）
4. 启动顺序：`NapCat → 引擎 → 面板 → 宿主管家`（见 `scripts/`）
5. 浏览器打开 `http://127.0.0.1:8898` 即得控制面板

本地大脑可选：任意 GGUF 小模型（推荐 3B 级，8GB 内存平板可跑 13+ tokens/s）。

## 📂 目录结构

```
engine/     tuanzi_service.py     机器人引擎（聊天/记忆/表情/语音/事件…）
panel/      panel_server.py       面板后端（标准库 HTTP + 状态聚合）
            dashboard.html        面板前端（单文件，零依赖，含离线演示模式）
config/     config.example.json   配置模板（复制为 config.json 后填写）
scripts/
  host/     宿主侧脚本（启动器/守护/热更/视觉切换/部署推送）
  device/   设备侧脚本（引擎/面板/管家/NapCat 启动与热重启）
tools/      表情包工具链（ComfyUI 批量生成 / 后处理 / 备注写入）
docs/       架构说明 + 面板交互设计规格
assets/     表情包示例（AI 生成）
```

## 🧰 技术栈

- Python 3（标准库为主，零第三方依赖运行）
- llama.cpp（本地推理）/ OpenAI 兼容云 API（可选）
- NapCat QQ（OneBot v11 协议）
- 原生 HTML/CSS/JS（面板，无构建、无框架、单文件）
- Shell（宿主守护与部署）
